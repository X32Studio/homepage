**self-loop**（`v0.8.0`，MIT 开源，零 `npm install` 依赖）是 X32 Agentic 工程栈的第 1 层：在 AI 时代，人最宝贵也最大的瓶颈是 **Attention（注意力）**，能否把多 Agent 管成一支真正可信的交付团队，决定了一个人的能力上限。

没有治理的 Agent 群落只是混乱的乌合之众。`self-loop v0.8.0` 将三套引擎首尾相连——**规划生成引擎**（计划与包契约）、**解耦调度与集成引擎**（基于 `arch-facts` 依赖图分析独立波次、并行调度 Actor 并校验无冲突合入）以及**对抗验收引擎**（单/多并行 Critic + 跨厂商 **Judge** 干净检出独立裁决）——并内置双循环防腐扫描、有界重构窗口、SSOT 权威文档漂移硬门禁、零配置仓库内 `.self-loop/`、Claude Code / Codex / Antigravity（T3 Code）适配以及 GitHub Actions / AWS CodeBuild 实时 CI 门禁。

**输入混乱群落与目标，输出可信赖的 Agent Coding Team 与经验证的生产代码。**
