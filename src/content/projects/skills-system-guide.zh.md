Anthropic 的官方文档只讲了单个 skill 怎么写，这本指南补上了缺失的那一层：多个 skill 作为系统如何协同。你会了解触发冲突从何而来、什么时候值得新建一个 skill，以及如何让不断增长的 skill 库保持连贯而不是混乱。

包含完整的 HTML 排版指南和中英双语文档。
