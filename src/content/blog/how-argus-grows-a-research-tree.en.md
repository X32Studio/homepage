Most research tools stop at "here are ten links". Argus is built around a different idea: a topic deserves a living structure, not a pile.

The loop has five moves:

1. **Search** a new angle of the field.
2. **Save** what matters into the tree, not into a chat that scrolls away.
3. **Connect** sources, claims, projects, and people into relationships you can see on the dashboard.
4. **Verify** — weak or missing branches are marked, not hidden.
5. **Dig** where it matters next round.

Because every pass writes back to the same tree, the report gets sharper over weeks instead of restarting from zero every session. The dashboard shows which branches grew, so coming back feels like checking on a garden, not re-reading a log.

The full setup guide lives in the [Argus repo](https://github.com/X32Studio/Argus). One Claude Code skill, one folder per topic, one command to start.
